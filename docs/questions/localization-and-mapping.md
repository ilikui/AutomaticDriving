# 专题：定位与建图

**题目范围：** 完整问题库第 21–30 题，并关联第 114–115 题的坐标变换测试方法。

## 学习目标

- 解释 GNSS、IMU、轮速里程计、视觉/激光里程计的互补关系与典型失效模式。
- 理解状态估计、点云配准、回环检测、地图定位与无地图定位的基本问题定义。
- 为定位输出设计质量状态、置信度监控和下游降级策略。

## 推荐顺序

1. 先完成[基础与传感器专题](foundations-and-sensors.md)，确保坐标系、时间戳与噪声概念清晰。
2. 阅读完整问题库第 21–30 题，梳理从传感器测量到状态估计、建图和定位质量的关系。
3. 使用 [LAB-001 一维 Kalman Filter](../../labs/python/kalman_1d.py)学习预测与观测更新；它是教学用的一维简化模型。
4. 用 [LAB-002 坐标变换](../../labs/python/coordinate_transform_2d.py)验证坐标变换链的方向和逆变换。

## 需要重点区分

- **状态估计不等于 SLAM：** Kalman 示例用于解释估计思想，不包含地图构建、特征匹配或回环检测。
- **算法精度不等于系统可用性：** 除位置误差外，还应关注可用率、跳变、漂移、置信度和失效恢复时间。
- **定位降级是系统行为：** 应定义质量门限、告警、速度/功能限制及安全策略，而不是只输出一个坐标。

## 实践检查清单

- [ ] 区分测量噪声、系统偏置与累计漂移。
- [ ] 明确评测真值来源、对齐方式、时间窗口和误差统计方法。
- [ ] 分析 GNSS 退化、IMU 偏置、轮速异常和地图不匹配等场景。
- [ ] 为低置信度、跳变与传感器失效设计可观察的降级行为。
