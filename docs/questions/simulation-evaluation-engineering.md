# 专题：仿真、评测与工程验证

**题目范围：** 完整问题库第 71–100、101–110、121–123、131–142、146–150 题。

## 学习目标

- 选择与研究问题相匹配的数据集、基线、评价指标和场景范围。
- 区分开放环与闭环评测、仿真通过与道路安全证据，以及功能安全、SOTIF 与一般软件质量。
- 建立可复现的运行记录、回归集、失败案例和需求—测试—结果的追踪关系。

## 推荐顺序

1. 阅读完整问题库第 71–80 题，先确定数据集、仿真和评价协议。
2. 阅读第 81–100 题，梳理软件接口、部署、系统故障与安全验证。
3. 用第 101–110 题建立调试、日志、边界测试和最小复现数据集的方法。
4. 用第 121–150 题补充跟踪/预测/控制指标、场景回归、数据泄漏和研究复现检查。
5. 参考 [CARLA 复现指南](../carla-reproducibility.md) 和 [场景模板](../../labs/carla/scenario-template.yaml)记录配置。

## 最小复现实验应包含

- [ ] 代码提交、软件/依赖版本和运行环境。
- [ ] 数据来源、版本、切分策略、场景配置与随机种子。
- [ ] 基线、唯一主要变量、评价指标和统计窗口。
- [ ] 成功、失败、超时和异常终止条件。
- [ ] 原始日志、失败样例、指标汇总与已知局限。
- [ ] 回归前后结果，以及无法复现时的差异分析。

## 工程验证边界

- [CARLA 场景复现指南](../carla-reproducibility.md)提供记录方法，不代表本仓库已在当前环境运行 CARLA。
- [Python Labs CI](../../.github/workflows/python-labs.yml)针对现有小型 Python 实验执行测试，不代表自动驾驶整车系统完成验证。
- 公开数据集上的指标提升不能单独证明闭环安全；安全结论需要与场景覆盖、失效分析和相应验证证据共同解释。
