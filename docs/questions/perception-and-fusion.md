# 专题：环境感知与多传感器融合

**题目范围：** 完整问题库第 31–50、116–120、143–145 题。

## 学习目标

- 区分 2D/3D 检测、分割、目标跟踪与多传感器融合的输入输出和评价指标。
- 理解数据级、特征级、目标级融合的差异，以及融合前的坐标、时间和目标关联要求。
- 识别独立噪声假设、异常值、置信度失准和数据分布偏移带来的风险。

## 推荐顺序

1. 从完整问题库第 31–40 题建立感知概念与指标基础。
2. 继续第 41–50 题，比较融合层级、关联、Kalman Filter 与消融实验。
3. 结合第 116–120 题，重点检查时间偏差、观测冲突、噪声方差和鲁棒门限。
4. 结合第 143–145 题，研究长尾场景分层评价和精度—延迟—资源的联合基准。

## 当前可运行实验

- [LAB-003 标量融合](../../labs/python/sensor_fusion_1d.py)：逆方差加权基线，假设观测无偏、已对齐且相互独立。
- [LAB-005 鲁棒融合](../../labs/python/sensor_fusion_robust.py)：中位数/MAD 门控与加权融合；小样本鲁棒性有限。
- [LAB-008 时间与协方差](../../labs/python/sensor_fusion_timing_covariance.py)：时间偏差门控与已知协方差下的标量估计。

这些示例不等同于完整的相机—雷达—激光雷达融合系统；尚未覆盖深度学习检测器、真实多目标关联和完整跟踪链路。

## 建议的验证设计

- [ ] 与单传感器和简单加权基线比较，并报告 RMSE 或任务相关指标。
- [ ] 分别注入异常值、时间偏差、相关噪声和观测缺失。
- [ ] 记录被门控的观测、阈值依据及错误接受/错误拒绝案例。
- [ ] 对感知任务报告数据划分、类别分层、场景条件与推理延迟。
- [ ] 通过消融实验判断收益来自融合逻辑还是数据/评价协议差异。
