# 专题：行为预测、规划与控制

**题目范围：** 完整问题库第 51–70、124–130 题。

## 学习目标

- 区分行为预测、轨迹预测、路径规划、速度规划和行为决策。
- 理解规划约束、轨迹可行性、舒适性与不确定性之间的权衡。
- 使用可解释的车辆运动学模型建立轨迹跟踪基线，并分析参数、速度与延迟的影响。

## 推荐顺序

1. 阅读完整问题库第 51–60 题，建立预测与规划的概念边界。
2. 继续第 61–70 题，掌握车辆模型、PID、Pure Pursuit、Stanley 与 MPC 的基本差异。
3. 阅读第 124–130 题，关注预测指标、控制误差统计、前视距离、延迟和转向约束。
4. 运行 [LAB-004 Pure Pursuit](../../labs/python/pure_pursuit.py) 与 [LAB-007 前视距离扫描](../../labs/python/pure_pursuit_sweep.py)，比较不同参数下的误差趋势。

## 实验记录建议

- 记录参考轨迹、车速、轴距、前视距离、转向约束和仿真步长。
- 同时报告横向误差、航向误差、最大误差和有效样本数，不只展示单张成功轨迹。
- 对直线、弯道、变曲率、速度变化和执行器延迟分别设计场景。
- 参数扫描应报告实际结果；不要预设自适应前视距离必然优于固定参数。

## 当前覆盖边界

现有 Pure Pursuit 实验是运动学教学模型，不包含完整动力学、障碍物规划、独立轨迹预测模型或真实执行器模型。A*、Hybrid A*、MPC 等算法应在后续以独立基线和测试集建设，不能将概念文档视为已实现功能。
