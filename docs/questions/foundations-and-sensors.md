# 专题：基础、数学与传感器

**题目范围：** 完整问题库第 1–20、102、111–115 题。

## 学习目标

- 解释自动驾驶系统的数据流与常见坐标系，能够明确变换方向、单位和参考系。
- 区分传感器内参、外参、时间戳、采样周期、传输延迟与时钟偏差。
- 为消息和离线数据定义明确的数据契约：时间基准、坐标系、单位、有效期、质量状态。

## 推荐顺序

1. 先学习[系统学习路线](../learning-roadmap.md)中的数学、ROS 2 与传感器阶段。
2. 阅读完整问题库第 1–20 题，再思考第 102、111–115 题的工程化延伸。
3. 使用 [LAB-002 二维坐标变换](../../labs/python/coordinate_transform_2d.py) 检查矩阵组合、逆变换与变换方向。
4. 使用 [LAB-008 时间同步门控](../../labs/python/sensor_fusion_timing_covariance.py)理解时间偏差拒绝策略；注意该实验不包含插值、运动补偿或时钟漂移估计。

## 实验检查清单

- [ ] 明确采用的坐标变换约定，并验证往返变换误差。
- [ ] 检查角度/长度单位、矩阵维度与组合顺序。
- [ ] 构造正常时间戳、超阈值偏差与边界值用例。
- [ ] 记录时间误差可能转化为空间误差的条件与假设。

## 常见误区

- 只看变换矩阵数值，不确认源坐标系与目标坐标系。
- 把消息到达时间当作传感器采集时间。
- 将合成实验的通过结果直接当作真实传感器标定或同步已经合格的证据。
